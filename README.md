🧮 Advanced Scientific Calculator

A powerful, all-in-one scientific calculator designed to handle everything from basic arithmetic to advanced mathematical operations, including number theory, exponentiation, roots, and logarithms.

The goal is simple: bring essential mathematical functions together in one convenient place, so you don’t have to rely on a traditional scientific calculator with its confusing buttons and complicated interface.

📌 About the Project

This Advanced Scientific Calculator is a personal project designed to make mathematical calculations accessible, convenient, and straightforward.

From everyday arithmetic to more specialized calculations such as permutations, combinations, factorials, HCF, LCM, exponential functions, and logarithms, the application brings a wide range of mathematical tools together in a single interface.

The core mathematical logic was designed and implemented manually by me, while Claude Code assisted me in developing the frontend and backend.

🚧 Project Status: Under Development

This project is still under development, and I plan to improve it gradually by refining existing features, enhancing the user interface, improving error handling, and introducing additional mathematical functions.

✨ Features

➕ 1. Basic Arithmetic

Addition (+) — Adds two numbers.
Subtraction (−) — Subtracts one number from another.
Multiplication (×) — Multiplies numbers.
Division (÷) — Divides one number by another.
🔢 2. Number Theory

Combinations (nCr) — Calculates the number of ways to select items when order does not matter.
Permutations (nPr) — Calculates the number of ways to arrange items when order matters.
Factorial (n!) — Calculates the factorial of a non-negative integer.
HCF — Finds the Highest Common Factor of integers.
LCM — Finds the Least Common Multiple of integers.
Integer Square Root (⌊√⌋) — Calculates the integer square root, rounded down.
📈 3. Powers, Roots & Exponential Functions

Square Root (√x) — Calculates the square root of a number.
Cube Root (∛) — Calculates the cube root of a number.
Power (xʸ) — Raises a number to a specified exponent.
eˣ — Calculates the exponential function with base e.
2ˣ — Calculates two raised to a specified power.
eˣ − 1 — Calculates the exponential function minus one.
📊 4. Logarithmic Functions

log(x) — Calculates a logarithm according to the function’s implemented base.
ln(1 + x) — Calculates the natural logarithm of one plus x.
log₂(x) — Calculates the logarithm to base 2.
log₁₀(x) — Calculates the logarithm to base 10.

How to Run This Calculator

Install Python 3 Download it from python.org if you don’t have it.

Download the project Click Code → Download ZIP on this repository, then unzip it.

Open a terminal in the project folder Open the calculator-app folder in your terminal.

Install the requirements (only once)

pip install -r requirements.txt

Start the app
python app.py

Open it in your browser Go to http://127.0.0.1:5001
